# No School of English — Landing Page

Современный, чистый и безопасный одностраничный сайт (Landing Page) для онлайн-школы английского языка **No School of English**. Разработан на чистом HTML5, CSS3 и ванильном JavaScript, идеально подходит для бесплатного хостинга на **GitHub Pages**.

---

## 📱 Как работает связь без сервера (на GitHub Pages)

Поскольку **GitHub Pages** предоставляет только статический хостинг (без бэкенда и БД):
1. **Переход в Telegram с готовым текстом**:
   - При нажатии на кнопку «Подобрать группу» или «Написать в Telegram» открывается модальное окно.
   - Пользователь вводит имя, возраст ребёнка, уровень и время.
   - При отправке JavaScript автоматически форматирует эти данные и открывает диалог в Telegram (`https://t.me/<username>?text=...`) с **уже набранным текстом**! Родителю остаётся только нажать кнопку «Отправить» в Telegram.
2. **Быстрый звонок по телефону**:
   - Номер телефона на всём сайте кликабелен (`tel:+...`) — при клике со смартфона сразу открывается набор номера.
3. **Прямой переход в Telegram**:
   - Ссылка на прямой диалог в мессенджере без необходимости заполнять форму.

## ⚙️ Настройка ваших контактов

Все контакты централизованно задаются в одном месте — в начале файла [`js/main.js`](js/main.js):

```javascript
const CONTACT_CONFIG = {
  // Использовать ли переход в Telegram по номеру телефона (true) или по юзернейму (false)
  usePhoneForTelegram: true,

  // Номер телефона для звонков и Telegram (в международном формате)
  phoneNumber: '+998901878844',

  // Как номер отображается на сайте
  phoneDisplay: '+998 90 187 88 44',

  // Юзернейм в Telegram (если решите переключить usePhoneForTelegram на false)
  telegramUsername: 'IrayugayGNBC',

  // Приветственный текст по умолчанию
  defaultMessage: 'Здравствуйте! Хочу узнать подробнее об онлайн-занятиях в No School of English.'
};
```
Скрипт автоматически обновит телефон и ссылки в шапке, карточках, модальном окне и футере на всем сайте.

## 🚀 Как выложить на GitHub Pages

1. Инициализируйте Git-репозиторий и закоммитьте файлы:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: No School landing page"
   ```
2. Создайте новый публичный репозиторий на [GitHub](https://github.com/new).
3. Привяжите удалённый репозиторий и запушьте код:
   ```bash
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
   git push -u origin main
   ```
4. В репозитории на GitHub перейдите в **Settings** → **Pages**:
   - В блоке **Build and deployment** выберите источник: **Deploy from a branch**.
   - Выберите ветку: `main` / root (`/`) и нажмите **Save**.
5. Через 1–2 минуты ваш сайт станет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## 🔍 Инструкция по SEO и выводу в ТОП

В проект уже внедрены все технические элементы для поисковиков:
- **Микроразметка Schema.org (JSON-LD)** для школы (`EducationalOrganization`), курса (`Course`) и блока вопросов (`FAQPage` для расширенного сниппета в Google).
- Мета-теги `Title`, `Description`, `Open Graph`, `Twitter Cards`.
- Файлы `robots.txt` и `sitemap.xml`.

### Как быстро проиндексировать сайт в Google и Яндекс:
1. **Google Search Console** ([search.google.com/search-console](https://search.google.com/search-console)):
   - Добавьте URL вашего сайта на GitHub Pages.
   - В разделе **Sitemaps** укажите: `sitemap.xml`.
   - В строке проверки URL введите адрес главной страницы и нажмите **«Запросить индексирование»**.
2. **Яндекс Вебмастер** ([webmaster.yandex.ru](https://webmaster.yandex.ru)):
   - Добавьте сайт и отправьте `sitemap.xml`.
3. **Локальное SEO (Google Maps & Яндекс Карты)**:
   - Зарегистрируйте карточку школы в **Google Мой Бизнес** и **Яндекс Бизнес**, привязав номер телефона и ссылку на сайт. Это даёт вывод в топ в блоке карт!
