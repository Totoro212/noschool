# No School of English — Landing Page

Современный, чистый и безопасный одностраничный сайт (Landing Page) для онлайн-школы английского языка **No School of English**. Разработан на чистом HTML5, CSS3 и ванильном JavaScript, идеально подходит для бесплатного хостинга на **GitHub Pages**.

---

## ⚙️ Настройка ваших контактов

Все контакты централизованно задаются в одном месте — в начале файла (js/main.js):

```javascript
const CONTACT_CONFIG = {
  // Использовать ли переход в Telegram по номеру телефона (true) или по юзернейму (false)
  usePhoneForTelegram: true,

  // Номер телефона для звонков и Telegram (в международном формате)
  phoneNumber: '+998901878844',

  // Как номер отображается на сайте
  phoneDisplay: '+998 90 187 88 44',

  // Приветственный текст по умолчанию
  defaultMessage: 'Здравствуйте! Хочу узнать подробнее об онлайн-занятиях в No School of English.'
};
```
